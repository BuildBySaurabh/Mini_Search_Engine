# Mini Search Engine

A Python-based desktop application that allows users to search **YouTube videos** and **web pages** from a single interface. Built with **Tkinter**, the application integrates the **YouTube Data API v3** and **Google Custom Search API** to provide fast and relevant search results in a clean, user-friendly GUI.

## Features

- Search YouTube videos directly from the application
- Display video thumbnails, titles, and descriptions
- Open YouTube videos and web pages with a single click
- Search web pages using Google Custom Search API
- Scrollable and responsive Tkinter interface
- Fast and accurate search results
- Simple, lightweight, and easy-to-use desktop application

## Technologies Used

- Python
- Tkinter
- YouTube Data API v3
- Google Custom Search API
- Requests
- Pillow (PIL)

## Project Overview

The Mini Search Engine combines YouTube and Google web search into a single desktop application. Users can enter a search query to instantly retrieve YouTube videos with thumbnails, titles, descriptions, and links, along with relevant web search results. The intuitive Tkinter interface makes browsing and accessing search results simple and efficient.
